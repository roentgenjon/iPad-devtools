🛠️ iPad DevTools

DevTools für
Chrome auf dem iPad

Ein vollwertiges Developer-Tools-Panel – direkt in jede Webseite injiziert. Console, Element-Inspector, CSS-Editor, Storage, Network, Befehle, Seiten-Editor, GUI-Editor und Einstellungen.

⚠️ Wichtig: Chrome auf iOS unterstützt keine Extensions (Apple-Beschränkung) und keine chrome://-Links. Dieses Bookmarklet umgeht diese Einschränkung – es injiziert ein vollwertiges DevTools-Panel direkt in jede Webseite.

📌 Bookmarklet installieren

Halte den Button gedrückt → „Lesezeichen hinzufügen“ – oder nutze die 3-Schritt-Anleitung unten.

🛠️ DevTools Bookmarklet Safari/Chrome: Link gedrückt halten → „Lesezeichen hinzufügen“
Alternativ: Lesezeichen manuell erstellen und URL ersetzen
1

Lesezeichen erstellen

Öffne Chrome auf dem iPad. Tippe auf ⋮ Menü → Lesezeichen → Lesezeichen hinzufügen. Nenn es DevTools.

2

URL durch den Code ersetzen

Gehe zu Lesezeichen bearbeiten, tippe auf den Eintrag und ersetze die URL komplett durch den kopierten Code unten.

3

Auf jeder Seite benutzen

Navigiere zu einer beliebigen Seite → tippe auf ☆ Lesezeichen-Icon → wähle DevTools. Das Panel erscheint sofort!
