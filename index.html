🛠️ iPad DevTools

DevTools für
Chrome auf dem iPad

Ein vollwertiges Developer-Tools-Panel – direkt in jede Webseite injiziert. Console, Element-Inspector, CSS-Editor, Storage-Manager und Network-Monitor.

⚠️ Wichtig: Chrome auf iOS unterstützt keine Extensions (Apple-Beschränkung) und chrome://-Links sind gesperrt. Dieses Bookmarklet gibt dir aber alle wichtigen DevTools-Funktionen auf jeder Seite.
🖥️
Console
JavaScript ausführen, console.log sehen, Fehler fangen, Eingabe-History mit ↑↓
🔍
Element-Inspector
Tippe auf jedes Element. Sieh den DOM-Baum, bearbeite innerHTML live
🎨
CSS-Editor
Computed Styles lesen & ändern, Inline Styles direkt setzen
🗄️
Storage
localStorage, sessionStorage & Cookies anzeigen, hinzufügen und löschen
📡
Network
fetch() und XHR-Requests abfangen – URL, Methode, Status-Code
📱
Touch-optimiert
Ziehen, Skalieren, große Tap-Targets – gebaut für iPad

📌 Schritt 1 – Bookmarklet speichern

Halte den Button gedrückt → „Lesezeichen hinzufügen" oder kopiere den Code und füge ihn manuell ein.

⊕ DevTools – Hierher ziehen oder gedrückt halten Safari/Chrome: Lesezeichen-Leiste einblenden → Button ziehen
Alternativ: Lesezeichen erstellen, dann URL durch den Code unten ersetzen
1

Lesezeichen erstellen

Öffne Chrome auf dem iPad. Tippe auf das ⋮ Menü → Lesezeichen → Lesezeichen hinzufügen. Nenn ihn z.B. DevTools und speichere ihn.

2

URL durch den Code ersetzen

Gehe zu Lesezeichen bearbeiten, tippe auf den gerade erstellten Eintrag und ersetze die URL komplett durch den kopierten javascript:…-Code unten.

3

Auf jeder Seite benutzen

Navigiere zu einer beliebigen Seite → tippe auf das ☆ Lesezeichen-Icon → wähle DevTools. Das Panel erscheint sofort. Nochmal tippen = schließen.
